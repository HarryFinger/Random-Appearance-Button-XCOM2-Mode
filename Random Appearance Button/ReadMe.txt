# Random Appearance Button - Extended

This mod is based on the original "Random Appearance Button" by thades.

Original mod: https://steamcommunity.com/sharedfiles/filedetails/?id=634268994

## Features

- Random Appearance button for generating reasonable-looking soldiers
- Totally Random button for completely random appearances  
- Additional buttons for specific traits:
  - Clear/Random Helmet
  - Clear/Random Upper face decorations
  - Clear/Random Lower face decorations
  - Clear/Random Hair (style only)
  - Hair Color randomization
  - Eyes Color randomization
- Checkbox system to lock specific traits
- Undo functionality with limited buffer
- Toggle Options panel

## Usage

Click "Toggle Options" to show/hide the trait locking checkboxes. Check the traits you want to preserve, then use the randomization buttons to generate new appearances.

The mod respects locked traits and provides fine-grained control over soldier customization.
